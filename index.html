1. Coral Reef Health Index (CHIcoral)

CHIcoral = (w1 · Live_Coral_Cover) − (w2 · Bleaching_Rate) − (w3 · Macroalgae_Cover)

Normalized weights: w1 = 0.50 (calcifying coral cover), w2 = 0.35 (thermal bleaching penalty), w3 = 0.25 (macroalgal competition). When CHIcoral ≤ 0, the system flags an Endangered Reef Phase-Shift Alert.
